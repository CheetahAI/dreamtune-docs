Connect your agent to tools, models, compute and observability using a scoped
Dreamtune API key. Hosted MCP requires no local Dreamtune server. Local stdio
lets your client launch the published package and manage local GPU SSH access.

Client formats differ. Copy the guide for your installed client instead of
renaming fields from another client's JSON. Roo Code is documented as a legacy
client because its official repository reports its shutdown.

## Choose the connection

| Need                                                           | Use                                             |
| -------------------------------------------------------------- | ----------------------------------------------- |
| Execute Dreamtune operations without installing a local server | [Hosted HTTP MCP](/connect/mcp)                 |
| Local CLI, stdio or automatic SSH key handling                 | [Local MCP](/connect/local-mcp)                 |
| Search this documentation without executing paid work          | [Documentation MCP](/connect/documentation-mcp) |
| Give your agent repeatable workflow instructions               | [Dreamtune skills](/connect/skills-install)     |
| Build an application                                           | [TypeScript SDK](/sdk)                          |

An MCP server exposes tools; your coding agent's selected model decides when to
request them. The Dreamtune key authorizes execution and billing. Adding MCP
does not replace your editor's own subscription or model connection.

## Verify before paid work

First discover tools and read model_limits or a catalog. Then inspect a selected
tool schema. Authorize a small, bounded execution only after confirming the
workspace, permissions and wallet. Save returned identifiers for recovery.

Review [security](/guides/security), [billing](/billing) and
[reliability](/guides/reliability) before granting broader access.
