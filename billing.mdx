Add credit in [Usage & billing](https://dreamtunelabs.com/dashboard/usage/).
The wallet belongs to the workspace. API keys spend from that workspace's
available balance according to their enabled capabilities.

## Agent crypto top-ups

Use SDK version 0.1.2 or hosted MCP to request crypto payment instructions and
check verified settlement. Create a key with Billing access in
[API keys](https://dreamtunelabs.com/dashboard/api-keys/). Existing keys retain
their original permissions. Your separately authorized wallet signs transfers;
Dreamtune never requests its private key or seed phrase.

Follow [the agent funding workflow](/guides/crypto-top-ups) for exact steps,
expiry and recovery. The [Billing API](/api/billing) documents routes, units,
permissions and errors; the [SDK](/reference/sdk#wallet-funding) and
[MCP tool reference](/reference/mcp-tools#wallet-funding) cover client methods.

## Optional key limits

You can set separate cumulative spending limits for models, tools and compute
when creating a key. A blank limit allows that category to use wallet credit.
It does not provide credit after the wallet is exhausted.

New paid work requires a positive balance and remaining applicable key budget.
One billable operation can be active per workspace across these categories.

## Model and tool settlement

Successful operations settle using confirmed actual cost and the saved server
billing policy. A final receipt can include:

| Field            | Meaning                      |
| ---------------- | ---------------------------- |
| `cost`           | Recorded execution cost      |
| `discountAmount` | Server-applied discount      |
| `fee`            | Recorded platform fee        |
| `total`          | Final charge                 |
| `chargedAmount`  | Committed charge for the run |

Amounts are integer strings in USD millionths: `"1000000"` means USD 1.00.
For a final receipt, `cost - discountAmount + fee = total`.
Pending runs do not contain a final cost breakdown. Failed new model/tool runs
have a zero final charge.

An operation that completes successfully can cost more than the remaining key
budget or wallet balance. Its confirmed cost still settles, and further work is
blocked until the admission requirements are met. Key limits are not guaranteed
maximum prices for a single upstream operation.

## Compute

Compute charges recorded runtime at the selected rate and billing policy.
Stop a rental explicitly when finished and confirm termination. See
[compute](/compute) for the full workflow.

## Payment confirmation

The platform funding fee is charged when you add credit. There is no additional
platform usage markup on model, tool or compute calls. Check current checkout
and pricing for the active fee and offers; gateway/network fees may also apply.
See [payment steps and troubleshooting](/guides/payments).

An agent crypto top-up API is awaiting rollout. See the [funding guide](/guides/crypto-top-ups)
and [billing endpoint reference](/api/billing) for its permissions and payment lifecycle.

A checkout return page is not itself proof that wallet credit was posted.
Check the dashboard's payment status and balance. Fund the owning workspace
before retrying a balance error.
