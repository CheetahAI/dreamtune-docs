## Choose your connection

| You are building with      | Use                         |
| -------------------------- | --------------------------- |
| The Dreamtune website      | Your browser and dashboard  |
| A Node.js application      | [TypeScript SDK](/sdk)      |
| A terminal                 | [Dreamtune CLI](/cli)       |
| An MCP-compatible agent    | [Hosted or local MCP](/mcp) |
| An agent that loads skills | [Bundled skills](/skills)   |

## Track the work

[Observability](/observability) connects requests to stages, sessions, captured
content and recorded usage. Access follows the workspace and scopes of your key.
[Billing](/billing) explains wallet credit, optional key limits and final receipts.

The SDK package is `@dreamtune/sdk`. Its local agent commands run on your own
computer; they do not create a hosted agent deployment. Use the documented
Dreamtune client methods rather than assuming OpenAI-compatible endpoints.
